Curse Stat-Block Builder

A guided foe builder from Creeps and Curses Chapter 2 §§2.1–2.2 (Classifications; Features and Scaling). Pick a classification and grade, tick class features, set a base CR — the sheet applies the universal traits for you, adds technique CR adjustments, and renders a printable stat block. Only the published features are implemented; anything the text leaves open is flagged GM ruling.
