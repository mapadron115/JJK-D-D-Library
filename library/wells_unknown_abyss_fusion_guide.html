Chimerafication

Custom rule: choose one base shadow and add up to three other tamed shadows. Each addition contributes one selected trait/ability plus one-quarter of that shadow's HP. The base shadow remains the chassis. No arbitrary Mahoraga prohibition exists; using it simply requires that you actually tamed it.
