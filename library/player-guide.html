Comprehensive Player Guide

This is the consolidated quick-reference spine for building characters with the library. Individual technique dossiers supply their own exact feature text; this page supplies the shared assumptions.

Character Foundations

Choose ancestry and class first.
Build the body, proficiencies, saves, hit points, and class chassis before selecting the Innate Technique.
Heavenly Restriction is a full player path.
A zero-CE Heavenly Restriction gains no Reserve Dice and cannot activate CE-dependent features, but physical, tactical, skill, and compatible cursed-tool features remain available.
Technique milestones.
1 / 3 / 6 / 11 / 18 are the normal major Innate Technique milestones. Explicit internal upgrades printed at other levels remain valid.
Technique DC.
8 + proficiency bonus + chosen CE ability modifier, normally Wisdom or Charisma unless the class explicitly says otherwise.

Cursed Energy, Stacking & Multiclassing

One reserve.
At level 1 take the starting class's Reserve Die. Each later class level adds that class's Reserve Die. Add the CE ability modifier once, then permanent bonuses.
One CE ability.
Choose Wisdom or Charisma when first gaining CE unless the starting class names another score. Multiclassing never creates another CE ability or pool.
Character level vs class level.
Total level sets proficiency bonus. Class-specific features use levels in that class unless they explicitly say character level.
Standard Innate Technique.
Multiclassing does not grant a second technique. Normal technique milestones use the highest individual level in a class that grants that technique, not combined class levels.
Dual Technique Variant.
A GM-approved character explicitly possessing two Innate Techniques advances both by total character level. Both share one CE Reserve, CE ability, action economy, Focus slot, reactions, and Domain/Burnout limits.
Same named effect.
Use the strongest instance and longest remaining duration; identical copies do not stack.
Damage amplifiers.
Distinct effects can combine unless expressly forbidden. Same-name effects do not. Named pinnacle effects still follow their explicit stacking restrictions.
Temporary HP / conditions.
Temporary HP never adds together. Repeated copies of the same condition do not intensify it unless the effect expressly says so.

Feats, Mindsets & Equipment

Technique feats.
Use the dedicated feats printed in the selected dossier. Normal techniques may carry up to four dedicated technique feats; intentionally X-tier concepts may exceed that when explicitly printed.
General feats and mindsets.
Use the project's audited feat/mindset options as ordinary character-building choices. Same-name effects never stack merely because they come from two sources.
Cursed tools.
Cursed tools supplement a character rather than granting a second Innate Technique. Activated properties use the wielder's CE unless the item explicitly provides another mechanism.
Special systems.
Djinn, Sacred Treasures, Ten Shadows, Omnitrix, Wyrdscript and other subsystem-heavy options use their own complete dossier rules where they differ from this shared baseline.
