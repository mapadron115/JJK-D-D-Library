# JJK D&D Complete Library — Ritual Archive

A GitHub Pages-ready static library for the complete Jujutsu Kaisen D&D 5e homebrew project.

## Included

- **244 indexed top-level dossiers** across techniques, cursed tools and subsystem primers.
- Canon JJK technique revisions, original/crossover codices, 28 Djinn, Sacred Treasures, One For All, Elden/Nen, anime/manga, video games, Marvel/DC and MTG.
- **Ten Shadows** as its current standalone archive with the level-1 subjugation ruling plus shikigami, Shadow Wearing, Wells Unknown Abyss and chimera supplements.
- **Omnitrix: Codon Archive**, including all 19 original-series forms in the guide and genome subjugation rituals.
- **Wyrdscript — Elder Futhark** with all runes and Bindrunes.
- Applied Systems, SCP-inspired techniques, both Bestiary sets and the 40-entry Cursed Tool Arsenal.
- Current player-facing core guide, advanced sorcery guide and 2026 repair ledger.
- Witch Hat material is intentionally excluded from this canon library.

## GitHub Pages

The site is pure static HTML/CSS/JavaScript. In repository **Settings → Pages**, deploy from the `main` branch and repository root. The included `.nojekyll` file keeps the source pages intact.

## Canon hierarchy

Newest explicit dossier text → 2026 Comprehensive Player Guide / Advanced Sorcery → unchanged Project V3 → ordinary 5e.

Major repairs include the 60-foot complete Domain baseline, initiative-count-20 sure-hit events, revised RCT Healing Reserve, explicit Dual Technique variant, and level-1 Ten Shadows subjugation access.
